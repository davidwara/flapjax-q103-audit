Methodology

  1. Day bounds. Converted 11-19 COT (UTC-5) to UTC timestamps, then located the exact first/last BSC blocks by timestamp (binary refinement against eth_getBlockByNumber). Note: BSC now produces a block roughly every 0.45 s (measured empirically from the RPC), so the day spans ~191,923 blocks, not the ~28,800 a 3 s/block assumption would give.
  2. Transfers. Queried eth_getLogs for the FLAPJAX Transfer event (0xddf252ad…) with from = treasury, over the full day range, in 10,000-block chunks, via public BSC RPC (bsc.publicnode.com). 11 logs returned; each decoded to recipient + amount (18 decimals).
  3. First BNB funder. For each recipient (and for the treasury itself) I found the first block where the account became active, using the monotonic predicate “balance > 0 OR nonce > 0” and binary search over the full chain history. Archive state was read from the Blast public BSC endpoint (bsc-mainnet.public.blastapi.io), which serves historical balance/nonce (publicnode and Binance dataseed do not serve archive state on their free tiers). The funding transaction was then read from that block’s full transaction list and re-verified individually with eth_getTransactionByHash. A recipient that has never held BNB and never sent a transaction (balance 0, nonce 0 today) has no first BNB funder — that is itself a finding, not a gap.
  4. Re-check. Every number on this page can be re-derived from the RPC with the commands in the “Reproduce” section. BscScan was not used: its v1 API now redirects to an Etherscan-v2 migration notice and its free tier reports “Free API access is not supported for this chain”, and the website is behind a Cloudflare challenge.
